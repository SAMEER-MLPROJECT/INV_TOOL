# AI assistance and third-party components

## AI-assisted development

This project was developed with substantial assistance from **Anthropic Claude** (an AI coding assistant), working
from a written specification supplied by the team and operating in a sandboxed development environment on
2026-10-31. The assistant wrote the large majority of the source code, the synthetic-data generator, the tests,
the documentation, the demo-recording script and the architecture diagram, ran the tests, and fixed the defects it
found. The team defined the problem framing, product requirements, constraints and acceptance criteria, and is
responsible for reviewing, understanding and presenting the work.

What the AI did **not** do: it did not use or have access to the team's earlier projects (UniAethel, CryptEthEra or
others); no code, data, results, screenshots or text from them are included. It did not access any real
organisation's data. All sample data is synthetic and generated by `scripts/generate_sample_data.py`.

The demo video was produced by a script (`demo/record_demo.py`) that drives the real application in a headless
browser and records it; the only overlay is a narration caption, labelled as such in every frame.

Teams should state AI use in their submission according to the organiser's rules.
